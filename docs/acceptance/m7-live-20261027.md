- 도구: `cargo test -p yw-app --test sol_live_probe -- --ignored --test-threads=1 --nocapture`(spec/09 §2.5 "SOL", `crates/yw-app/tests/sol_live_probe.rs`). yw-app의 `sol::rpc`·`sol::flow` 경로와 yw-win WinHTTP 클라이언트를 그대로 쓴다.
- 엔드포인트: 개발 설정 `%USERPROFILE%\.yw-dev\rpc.json`(spec/01 §4.6, 실제 경로가 저장소 밖인지 확인, 엄격 JSON ≤ 64 KiB), 키 `solana:mainnet`·`solana:devnet`. 공급자 QuickNode(D13). 기록에는 `NetworkId`만 쓴다(URL·호스트·토큰·서버 메시지 없음; 오류는 JSON-RPC 코드·HTTP 상태·전송 종류만).
- **서명·전송 없음**: 메시지는 서명하지 않은 채 `simulateTransaction`(`sigVerify:false`, `replaceRecentBlockhash:true`)·`getFeeForMessage`에만 넣었다. 보내는 주소는 `getVoteAccounts`의 검증자 identity 중 System 소유·잔액 충분한 공개 주소, 받는 주소는 무작위 32바이트다. 키·니모닉은 쓰지 않았다(앱 미리보기도 공개 주소만으로 승인 초안까지). `sendTransaction`은 한 번도 부르지 않았다.
- 작업 트리: main `8c35a86` 위의 M7 작업 트리(이 파일은 M7 커밋에 포함). 같은 날 여러 번 실행했고 모두 통과했다. 아래는 최종 실행(종료 코드 0, `1 passed`, 20.3 s).
- 판정 요약: **spec/07 §10 CU 측정·§16 공급자 행·§8.3 mint 확인 모두 기대대로.** `SOL_TRANSFER_CU_LIMIT = 600`(측정 최대 450 + 150)을 확정했다. 이전 실행과 다른 점은 devnet에서 고른 identity 주소와 서명 나이뿐이다(값 판정 동일).
