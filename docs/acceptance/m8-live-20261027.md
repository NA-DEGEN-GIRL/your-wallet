# M8 Bitcoin 실서비스 읽기 전용 확인 — 2026-10-27

- 범위: spec/08 §4.5 착수 검사 E1–E3(Esplora)·C1–C2(Core JSON-RPC), spec/09 §2.5 "BTC" 묶음, §5.10 M8-1. B1–B4(선택 인덱서 `bb-rpc`·`bb-rest`)는 쓰지 않기로 했으므로 하지 않았다(기본 인덱서 `esplora`).
- 엔드포인트: Core는 개발 설정 `%USERPROFILE%\.yw-dev\rpc.json`의 `bitcoin:mainnet`·`bitcoin:testnet4`(공급자 QuickNode, D13). 이 기록에는 `NetworkId`만 쓴다(URL·호스트·토큰·서버 오류 문구 없음). Esplora는 공개 mempool.space(`https://mempool.space/api`, `https://mempool.space/testnet4/api`, 비밀 아님, spec/08 §2).
- **전송 없음**: `sendrawtransaction`·Esplora `POST /tx`는 한 번도 부르지 않았다. `testmempoolaccept`에는 입력이 존재하지 않는 무효 거래(무작위 prevout, 서명 없음)만 넣었다. 키·니모닉은 쓰지 않았다(파생 확인은 공개 BIP84 시험 벡터의 공개 계정 노드만).
- 도구: (1) `curl.exe -s -i -H "Accept: application/json" <URL>` — 응답 원문을 `crates/yw-core/tests/vectors/btc/esplora/*.http`에 저장(목록·URL은 같은 폴더의 `README.md`), (2) 읽기 전용 Node 스크립트(스크래치, 저장소 밖, `rpc.json`을 읽고 URL·호스트·토큰을 가린 응답 본문만 출력) — Core 응답 본문을 `crates/yw-app/tests/fixtures/btc_core/*.json`에 저장, (3) `cargo test -p yw-app --test btc_live_probe -- --ignored --test-threads=1 --nocapture`(yw-app `btc::*` 경로와 yw-win WinHTTP 그대로).

## 판정 요약

**E1–E3·C1·C2 통과(M8 진행 조건 충족, spec/08 §4.5 판정).** 응답 형태는 spec/08 §4.3·§4.5 사전 실측과 같다. 한 가지 환경 이슈: mempool.space가 돌려주는 IPv4 주소 6개 중 2개(`103.165.192.202`, `.205`)가 이 PC의 네트워크에서 응답하지 않았다(curl `--resolve`로 주소별 확인: 4개는 0.6 s 안에 200, 2개는 8 s 시간 초과). curl은 다른 주소로 넘어가지만 WinHTTP(앱)·.NET은 그 주소에 걸리면 호출 기한 안에 응답을 받지 못해 E-BTC-001(원인 E-RPC-002)이 된다. 같은 시각 `https://blockstream.info/testnet4/api`는 정상. 코드 결함이 아니라 경로 문제로 보고, 계속되면 설정에서 `Esplora URL`을 다른 Esplora 서버로 바꾼다(spec/08 §4.5 대안). spec/08 §4.4는 시간 초과를 재시도하지 않으므로 이 경우 사용자가 `새로고침`/`다시 시도`를 누른다.

## 앱 경로 프로브 출력 (`btc_live_probe`)

첫 실행(mempool.space가 응답하는 주소로 연결된 동안):

```text
bitcoin:testnet4 check_chain (1-4)          ok  tip=157722 lag=None ms=1699
bitcoin:testnet4 estimatesmartfee 2         ok  sat_per_kvb=None
bitcoin:testnet4 estimatesmartfee 6         ok  sat_per_kvb=None
bitcoin:testnet4 estimatesmartfee 24        ok  sat_per_kvb=None
bitcoin:testnet4 getmempoolinfo             ok  mempoolminfee=100 minrelaytxfee=100 incrementalrelayfee=100 (sat/kvB)
bitcoin:testnet4 getmempoolentry (confirmed) ok  entry=Absent
bitcoin:testnet4 getrawtransaction+verify   ok  source=Core bytes=225 value=5840453620191
bitcoin:testnet4 tracking observation       ok  observation=Confirmed { height: 157695 } getmempoolentry_unsupported=false
bitcoin:testnet4 esplora utxo (public addr) ok  count=24 confirmed=24
bitcoin:testnet4 discovery (abandon account) err indexer=Unreachable(Some(Rpc002)) class=E-BTC-001
bitcoin:testnet4 testmempoolaccept (bogus)  ok  allowed=false reject=missing-inputs
bitcoin:mainnet  check_chain (1-4)          err indexer=Unreachable(Some(Rpc002)) class=E-BTC-001
```

이후 실행은 mempool.space의 응답 없는 주소에 걸려 `check_chain` 3단계(인덱서 제네시스)에서 E-BTC-001(원인 E-RPC-002)로 멈췄다(위 "환경 이슈"). Core 쪽 항목은 모두 통과했다.

같은 프로브를 Esplora 기준 URL만 `https://blockstream.info/api`·`https://blockstream.info/testnet4/api`로 바꿔(`YW_BTC_ESPLORA_MAINNET`·`YW_BTC_ESPLORA_TESTNET4`, 공개 서버) 다시 실행했다:

```text
bitcoin:testnet4 check_chain (1-4)          ok  tip=157727 lag=None ms=1677
bitcoin:testnet4 estimatesmartfee 2         ok  sat_per_kvb=None
bitcoin:testnet4 estimatesmartfee 6         ok  sat_per_kvb=None
bitcoin:testnet4 estimatesmartfee 24        ok  sat_per_kvb=None
bitcoin:testnet4 getmempoolinfo             ok  mempoolminfee=100 minrelaytxfee=100 incrementalrelayfee=100 (sat/kvB)
bitcoin:testnet4 getmempoolentry (confirmed) ok  entry=Absent
bitcoin:testnet4 getrawtransaction+verify   ok  source=Core bytes=225 value=5840453620191
bitcoin:testnet4 tracking observation       ok  observation=Confirmed { height: 157695 } getmempoolentry_unsupported=false
bitcoin:testnet4 esplora utxo (public addr) err indexer=Rejected class=E-BTC-005
bitcoin:testnet4 discovery (abandon account) ok  receive_next=155 receive_last=Some(154) change_next=102 change_last=Some(101) checked=297 ms=66728
bitcoin:testnet4 testmempoolaccept (bogus)  ok  allowed=false reject=missing-inputs
bitcoin:mainnet  check_chain (1-4)          ok  tip=973353 lag=None ms=1313
bitcoin:mainnet  estimatesmartfee 2         ok  sat_per_kvb=Some(136)
bitcoin:mainnet  estimatesmartfee 6         ok  sat_per_kvb=Some(128)
bitcoin:mainnet  estimatesmartfee 24        ok  sat_per_kvb=Some(126)
bitcoin:mainnet  getmempoolinfo             ok  mempoolminfee=100 minrelaytxfee=100 incrementalrelayfee=100 (sat/kvB)
```

- 발견: 공개 시험 니모닉 `abandon … about`의 testnet4 계정은 받기 0–154·잔돈 0–101이 이미 쓰였다(주소 297개 검사, 약 67 s, 요청 간격 200 ms). release 스모크의 발견 결과와 같다.
- blockstream.info는 이 공개 주소의 `/utxo`에 400을 주었다(E-BTC-005, spec/08 §4.3 대응대로). mempool.space는 같은 주소에 UTXO 24–26개를 주었다.
- mainnet 추정은 136·128·126 sat/kvB로 모두 하한 1,000 sat/kvB 미만(앱은 하한 적용).
- 이 프로브는 판정 항목이 하나라도 `err`이면 실패로 끝난다. 위 두 실행의 `err`는 각각 mempool.space 연결 문제와 blockstream.info의 400이며, 둘 다 앱의 분류(E-BTC-001·E-BTC-005)가 기대대로 동작한 것이다.
