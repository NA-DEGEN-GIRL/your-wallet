## 에뮬레이터가 덮지 못하는 것

- arm64 `libyw.so`의 전체 흐름(같은 소스의 arm64 빌드는 게이트가 만들고 검사하며, 시험 기기에서는 위 칸만큼만 돌았다).
- 하드웨어 TEE Keystore의 기기 키(에뮬레이터는 보호 하드웨어가 아니다): 시험 기기의 A2-4b·A2-8이 감싸고 풀기를 봤다. 화면 잠금이 있을 때의 경우는 여전히 주인 체크리스트(AND-K1–K3)다.
- API 29의 동작(최근 앱 축소판은 API 33 미만에서 `FLAG_SECURE`에만 기댄다)과 그 기기의 실제 배치.
- 제조사 전력 관리 아래의 백그라운드 잠금, 실제 손가락 터치(모두 `adb` 주입 입력이고, 두 손가락은 에뮬레이터의 터치 장치에 쓴 커널 사건이다). 처음 기록의 실행은 길이 0의 누름이 대부분이라 누르고 있는 버튼의 결함을 보지 못했다 — 뒤 단계의 실행은 150–500 ms의 누름을 쓴다.
