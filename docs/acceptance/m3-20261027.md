## 수동 체크리스트 (spec/09 §5.4, spec/04 §10)

### 준비

1. 저장소 루트에서 빌드한다.
   ```powershell
   cargo build -p yw-app --release --locked
   ```
2. 기존 데이터가 있으면 옮긴다(없으면 건너뜀). 앱이 꺼진 상태에서:
   ```powershell
   $v3 = "$env:LOCALAPPDATA\YourWallet\v3"
   if (Test-Path $v3) { Rename-Item $v3 "v3.bak" }
   ```
3. 시험 비밀번호는 `m3-test-password!`. Windows 설정 → 시스템 → 클립보드 → **클립보드 검색 기록**(Win+V) 켬. OBS Studio 설치.
4. 실행: `target\release\yw-app.exe`(탐색기에서 두 번 클릭해도 된다). 로그는 `%LOCALAPPDATA%\YourWallet\v3\logs\yw-app.log`. 로그 끝 확인:
   ```powershell
   Get-Content "$env:LOCALAPPDATA\YourWallet\v3\logs\yw-app.log" -Tail 20
   ```
5. 비밀 창(W01–W10) 입력: 칸 사이 이동은 Tab 또는 Enter, 마지막 칸의 Enter는 확인. W05(니모닉)는 공백·Tab으로 다음 단어. 한/영 키는 영문 상태로 둔다(UI-M3-05 제외).
