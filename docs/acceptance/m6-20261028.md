## 명령 ID 감사 (Part A)

## 수동 체크리스트 (M6-2·M6-3, 사용자 수행)

실제 AI 공급자는 사용자가 고른 OpenAI 호환 엔드포인트와 키를 쓴다. 고지 문구대로 dApp 요청 내용(주소·금액·서명 문구)이 그 공급자에게 간다. 시험용 지갑·Sepolia로 한다.

### 준비

- [ ] 1. 설정 → `AI 설명` 탭: 상태 줄이 "꺼짐 — 외부로 아무것도 보내지 않습니다"인지 확인한다(기본값).
- [ ] 2. `엔드포인트`에 선택한 공급자의 전체 주소를 넣는다(예: `https://<공급자 호스트>/v1/chat/completions`, 로컬 모델이면 `http://127.0.0.1:<포트>/v1/chat/completions`). `모델`에 모델 이름을 넣고 `저장` → "저장했습니다." `http://`로 외부 호스트를 넣으면 거부되는지도 본다.
- [ ] 3. `API 키`에 키를 붙여 넣고 `키 저장` → "저장된 API 키: 설정됨", 입력 칸은 비워지고 값은 다시 보이지 않는다(로컬 모델은 생략).
- [ ] 4. `연결 테스트` → 10초 안에 "연결 테스트 성공…". 실패하면 문구대로 조정한다: HTTP 400이면 `응답 형식`을 `json_object`로 바꾸거나 `max_tokens`를 1–4096으로 넣고 `저장` 뒤 다시(spec/06 §11). "AI 응답이 너무 큽니다"면 추론형이 아닌 모델로 바꾼다.

### 켜기와 고지 (M6-3)

- [ ] 5. `AI 설명 사용` 체크 → "AI 설명 켜기" 화면에 고지 7줄과 설정한 호스트(로컬이면 "이 PC의 로컬 서버(…)")가 보인다. `이해했습니다`를 체크하기 전에는 `켜기`가 꺼져 있다. `취소` → 아무것도 바뀌지 않는다(상태 줄 그대로).
- [ ] 6. 다시 체크 → `이해했습니다` → `켜기` → 상태 줄 "켜짐 — dApp 요청마다 …(으)로 요청 내용을 보냅니다".

### 설명 표시 (M6-3)

- [ ] 7. Sepolia dApp에서 ERC-20 `transfer`(T09)를 요청한다 → 승인 창이 평소보다 길게 열리고, 버튼 바로 위 보라색 패널 "AI 설명 (참고용, 틀릴 수 있음)"이 처음부터 있다("요청 해석과 시뮬레이션이 끝나면…" → "AI 설명을 요청하는 중…").
- [ ] 8. 설명이 도착하면 요약·동작 줄(`보냄 · <기호> <금액> · <보낸 주소> → <받는 주소>`, 주소는 전체)·"AI가 판단하지 못한 것"·꼬리 줄(`호스트 · 모델 · n.n초`)이 패널 안에만 보인다. **도착 전과 후의 `거부`·`승인` 버튼, 경고, 확인 체크박스 위치가 같다**(도착 전후 화면을 캡처해 비교).
- [ ] 9. 패널 안 글자는 선택·복사·클릭이 되지 않고, 패널을 클릭해도 Tab 포커스가 버튼에 남는다. 글이 길면 패널 안에서만 휠로 스크롤된다.
- [ ] 10. 설명이 오기 전에도(무장 1초 뒤) `승인`이 켜지고, AI 결과와 관계없이 위험 등급·경고·체크박스 요구가 같다. 승인하면 평소대로 서명·전송된다.
- [ ] 11. Permit2 typed data 서명(T23)과 `personal_sign`·로그인(SIWE)을 각각 요청 → 패널에 설명 1회씩.
- [ ] 12. 지갑 화면에서 직접 보내기(EVM·Solana·Bitcoin)는 승인 창에 AI 패널이 없다.

### 실패해도 승인은 정상 (M6-3)

- [ ] 13. 엔드포인트를 존재하지 않는 주소(예: `https://api.example.invalid/v1/chat/completions`)로 바꿔 `저장` → AI 설명이 꺼졌다는 안내 → 다시 켜기(새 호스트 고지 확인) → dApp 요청 → 패널에 한 줄 "AI 공급자에 연결할 수 없습니다", `다시 요청` 버튼(마우스로만), 승인·거부·경고는 정상.
- [ ] 14. 키를 틀린 값으로 저장 → "AI API 키가 거부되었습니다", 승인 정상. `다시 요청`을 거듭하면 승인 창당 3번째 뒤 "AI 설명 요청 횟수를 모두 사용했습니다".
- [ ] 15. 응답이 늦는 공급자(또는 네트워크 차단)에서 10초 뒤 "AI 응답 시간 초과(10초)", 그동안에도 승인 가능.

### 끄기 (M6-2)

- [ ] 16. `AI 설명 사용` 해제 → 상태 줄 "꺼짐". 지갑 보내기(M4-2)와 dApp 요청을 해도 승인 창은 원래 크기, AI 패널 없음.
- [ ] 17. `logs\yw-app.log`에서 끈 뒤의 `llm_explain` 줄이 0이고, `resmon`(네트워크 탭)이나 `netstat -b`로 본 외부 연결 대상이 설정한 RPC 엔드포인트뿐이다(기록에는 호스트 대신 `NetworkId`).
- [ ] 18. 켠 동안의 로그는 요청마다 `llm_explain gen=… kind=… result=… reason=… http=… req_bytes=… resp_bytes=… elapsed_ms=… host=<호스트>` 한 줄씩이고, 프롬프트·응답 문장·주소 설명·API 키·`Authorization`·엔드포인트 경로가 없다.
- [ ] 19. 시험을 마치면 필요에 따라 `키 삭제`로 API 키를 지운다("없음").
