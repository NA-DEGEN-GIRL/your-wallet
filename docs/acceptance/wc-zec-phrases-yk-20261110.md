# WalletConnect · Zcash · 복구 단어 여러 개(D37) · YubiKey(11-10) 수동 확인 기록 — 2026-11-10 (모두 대기, 사용자 수행)

- 범위: docs/acceptance에 수동 기록이 없던 기능을 오늘의 화면 이름으로 — WalletConnect([spec/13](../../spec/13-walletconnect.md) §5–§7·§10: 7bbeaa5의 거절 알림·`연결 확인 중`·확인 없는 세션 끊기·"일치(서버 알림)", ccdca60·ae3c14d의 연결 창 태그·앱 거절 알림), Zcash([spec/12](../../spec/12-zcash.md) §11·§14.2), 복구 단어 여러 개 D37([spec/02](../../spec/02-core-keys-vault.md) §8.6, [spec/04](../../spec/04-app-ui.md) §2.7·§2.24, [spec/05](../../spec/05-browser.md) §4.2·§4.9), YubiKey 등록·PIN의 11-10 동작([spec/10](../../spec/10-yubikey.md) §7.3·§7.4·§9, ee9a875). YubiKey 연결(복구 단어 없이)은 [yubikey-20261104.md](yubikey-20261104.md) Y-40–Y-47, 키 지우기·슬롯 구성 바꾸기는 [yubikey-manage-20261106.md](yubikey-manage-20261106.md).
- 자동 항목은 게이트(`scripts/check.ps1 -Offline`)의 시험이 맡는다. 여기에는 실제 RPC·dApp·카드가 필요한 항목만 둔다.
- 안전 규칙: 테스트넷(Sepolia·Zcash testnet·Bitcoin testnet4·Solana devnet)과 소액만. 복구 단어는 테스트용 새 단어. YubiKey는 다른 용도(GPG·PIV 인증서·SSH)로 쓰지 않는 카드. 항목마다 결과(화면 문구·상태)를 적는다.
- 창 크기: 기본 창(960×680) 그대로 한다. 보내기 폼에서 `검토`·승인·서명의 결과가 **`검토` 바로 위 줄**에 보이는지(맨 위 띠가 아니라)도 확인 항목이다(spec/04 §2.7, 2026-11-10).
