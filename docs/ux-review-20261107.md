## 2. 고친 것 (전 → 후)

- **F1 WalletConnect**: 상단 막대 `연결된 사이트` → `사이트·WalletConnect`, 화면 제목 "연결된 사이트" → "연결된 사이트 · WalletConnect". Project ID가 없으면 카드는 "WalletConnect 연결 — 처음 한 번 준비": 소개 → `릴레이` → "1단계: Reown Project ID 저장"(입력 칸 + 주 버튼 `저장` + 어디서 받는지) → "2단계: dApp에 연결"(저장하면 연결 칸이 나타난다는 한 줄). 꺼진 연결 컨트롤은 그리지 않는다. Project ID가 있으면 연결 칸·QR 읽기가 먼저이고 Project ID는 값 한 줄 + `Project ID 바꾸기 ▸`(펼치면 입력 칸·`저장`; 비우고 저장하면 끔). 설정 → 브라우저·진단·정보에 카드 "WalletConnect"(무엇인지, 상태 `Project ID 없음 — 꺼져 있음`/`Project ID 설정됨 · 세션 n개`, `연결된 사이트 · WalletConnect 열기`). 18: 회색 버튼 세 개 → 1·2단계 카드. 시험 `walletconnect_panel_asks_for_the_project_id_first`.
- **F2 Ctrl+4**: 숫자 키 판정을 `events::chain_tab_key`('1'–'4' → 탭 1–4)로 옮겨 관찰자가 Ctrl+4도 넘긴다. 단축키 줄 "Ctrl+1 / 2 / 3 / 4 체인 탭(EVM·Solana·Bitcoin·Zcash)". 시험 `ctrl_4_is_the_zcash_tab`.
- **F3 설정 지도**: 구역 탭 아래 한 줄 "이 구역: …"(`ui::screens::settings_map`) — 그 구역의 카드들과, 설정 밖에 있는 관련 기능의 자리(토큰 추가 → 메인 토큰 카드, Bitcoin 계정·주소 방식 → Bitcoin 탭, Zcash 켜기 → Zcash 탭, YubiKey 서명 → 승인 뒤 PIN 창). 네트워크(RPC)에서 "rpc.json에서 가져오기" 버튼 카드는 맨 아래로(가져오기 확인 카드는 결정을 기다리므로 그대로 맨 위), 도움말의 "아래 목록" → "위 '네트워크별 RPC 주소' 목록". 17: 첫 카드가 rpc.json → RPC 공급자. 시험 `settings_sections_start_with_their_map`.
- **F4 무장 안내**: 내용·확인 체크는 갖춰졌고 창의 시간 조건만 남았을 때 상태 줄 끝에 "잠시 뒤 버튼이 켜집니다 (실수 클릭을 막는 1초 대기)", 창이 뒤에 있으면 "이 창을 클릭해 앞으로 가져오면 1초 뒤 버튼이 켜집니다"(`ApprovalSession::arm_waiting`). 무장 계산(`can_approve`, 대기 재시작, 누름 간격)은 그대로이고 확인 체크가 필요한 고위험 창(13)이나 차단 창에는 이 문구가 없다(사용자가 할 일이 남았으므로). 12 등: 남은 시간만 → 이유 한 줄. 시험 `arm_waiting_is_only_the_window_timing`.
- **F5 알림 색**: 배너에 색을 두고(`Banner.tone`, 기본 빨강) 코드 없는 알림은 `App::notice(text, tone)`로 — 제네시스 첫 고정은 정보(파랑), HyperEVM 미등록은 주의(노랑). 설정 파일 변조·되돌림 경고(LLM 강제 끔, genesis 복원, vault 세대 역행)는 빨강 그대로. `알림 닫기`는 모두 닫는다. 시험 `notice_banners_keep_their_tone`.
- **F6 Zcash 탭**: 엔드포인트가 없으면 네트워크 카드에 링크 `RPC 설정하기`(꺼짐 카드에서도 두 네트워크 모두 URL이 없으면), 문구 "설정 → 네트워크(RPC)에서 Zcash 주소를 넣으세요", 같은 E-KEY-005는 탭 위 빨간 띠로 반복하지 않음(다른 Zcash 오류는 그대로 띠). 꺼짐 카드 제목 "Zcash (일반 주소 전용)", "(D36)" 삭제, "Zcash 엔드포인트(zcash:<net>)가 필요합니다" → "먼저 설정 → 네트워크(RPC)에서 그 네트워크의 Zcash 주소(zcash:mainnet·zcash:testnet)를 넣으세요". 네트워크 칩에 Zcash 배지, 네트워크 띠는 네트워크 카드 안. 47·48(새). 시험 `zcash_missing_endpoint_is_one_line_with_the_next_step`.

## 3. 점검 항목별 결과

- **기능 찾기**: WalletConnect(F1), YubiKey(설정 → YubiKey; 서명은 승인 뒤 저절로 — 지도 줄에 적음), 주소록(상단 막대, 보내기 폼의 ★ 칩·`주소록에서 선택`), HyperCore(EVM 탭 아래 카드, 설정은 EVM 체인 구역 — 지도 줄). Chrome 확장은 완료 화면·빈 연결 목록·설정에서 이어진다.
- **이동 깊이(클릭)**: 받기 1, 보내기 3 + 승인, 체인 바꾸기 1(또는 Ctrl+1–4), 확장 연결 = 사이트에서 1 + 연결 창, WalletConnect 연결 = 상단 `사이트·WalletConnect` → 붙여 넣기 → `연결` + 연결 창(처음 한 번 Project ID 저장), 승인 = 창에서 1(고위험은 체크 + 2초), 토큰 추가 2(토큰 카드 → 주소 → 확인), YubiKey 서명 = 승인 + PIN 창.
- **탭 과부하**: 체인 탭 4개는 한 줄에 들어가고 각 탭의 배치(네트워크 → 선택 계정 → 계정 목록 → 토큰/UTXO → 활동)가 같다. Zcash 탭만 한 화면에 받기·보내기를 모두 펼치는데(spec/12 §11의 한 화면 설계) 계정이 하나라 길이는 비슷하다. HyperCore 카드는 남김(D3).
- **설정 구성**: F3. 8개 구역은 한 줄에 들어가고(943 px), 선택한 구역이 채워진다.
- **용어**: 복구 단어(니모닉) — F9 뒤 남은 "니모닉"은 처음 언급의 "(니모닉)", §7 오류 문구(E-INP 등, 코드 고정), 로그·AI 고지(보내지 않는 것 목록). "가져온 키"·"YubiKey" 배지, "확정", Zcash "일반(transparent) 주소"는 일관된다.
- **빈 상태**: 모두 다음 행동이 있다. Zcash 꺼짐 카드에 RPC 다음 단계를 더했다(F6).
- **경고·띠 피로**: 체인 탭마다 네트워크 띠는 하나. 새로 더한 HyperCore 메인넷 띠(F7)는 실제 자산을 옮기는 카드의 표시라 남긴다. Zcash의 중복 띠를 없앴고(F6), 정보성 알림을 빨강에서 내렸다(F5).
- **승인 창 가독성**: 무엇(요약)·어디(요청 출처·네트워크)·얼마(자산 변화)·위험(띠·태그)이 첫 화면에 있다. 회색 버튼의 이유를 더했다(F4).
- **오류의 다음 단계**: 엔드포인트 없음은 EVM·Solana·Bitcoin·Zcash 모두 `RPC 설정하기`(F6로 Zcash 추가). §7 문구 자체는 바꾸지 않았다(E-KEY-005의 "설정 → 네트워크 URL"은 탭 이름 "네트워크(RPC)"와 조금 다르다 — D6).
- **키보드·포커스**: Tab 순서는 화면 배치 순서(위 → 아래, 줄 안 왼쪽 → 오른쪽)이고 상단 막대도 왼쪽부터다. Ctrl+L, Ctrl+1–4(F2). 승인 창 Tab·Enter·Space·Esc·PgUp/PgDn은 그대로.
- **DPI 100/150%**: 크기는 모두 DIP. 상단 막대는 이름이 길어졌어도 최소 창 폭 720 DIP에서 오른쪽 버튼 묶음이 제목("Your Wallet")과 겹치지 않는다(버튼 폭 합 약 470 DIP, 제목 오른쪽 끝 약 120 DIP). 투어는 100%만 찍으므로 125–200%는 여전히 수동 확인 항목이다.
- **체인 배지**: HyperCore(F7)·Zcash 칩(F6)을 더해 spec §1.6.1과 맞췄다.
- **스크롤**: 바뀐 화면 모두 기존 스크롤 규칙(배치 고정, 이동만)을 따른다. 설정 지도 줄은 탭 줄 바로 아래 한 줄이라 첫 화면 높이를 거의 바꾸지 않는다.

## 4. 남긴 것과 이유·대안

- **D1 단순 송금의 "보내는 자산만 있고 받는 자산이 없습니다"**(10-31 D2 그대로): 시뮬레이션 해석의 위험 경고라 이번 범위(보안 동작 약화 금지) 밖이다. 제안: calldata 없는 네이티브 전송이고 자산 변화가 "보냄 {금액}" 한 줄과 정확히 같을 때만 `정보`로 내린다.
- **D2 설정 검색**: 구역 8개와 지도 줄(F3)로 찾을 수 있다고 보고 미뤘다. 카드가 더 늘면 탭 줄 오른쪽 검색 칸 → 카드 제목·지도 줄 문구에서 찾아 그 구역으로 이동하는 방식을 제안한다(값·비밀은 검색 대상에서 뺀다).
- **D3 HyperCore 카드의 자리**: spec/11 §8은 설정이 켜져 있으면 EVM 탭의 모든 체인에서 카드를 보인다. HyperEVM·Arbitrum이 아닌 체인(예: Sepolia)에서는 버튼 6개가 늘 보여 길다. 숨기면 잔액을 놓칠 수 있어 이번에는 띠·배지만 더했다. 제안: 선택 체인이 HyperEVM·Arbitrum이 아니면 카드를 한 줄("Hyperliquid HyperCore 메인넷 · 계정 가치 … · 펼치기 ▸", 실행 중에만 기억)로 접는다.
- **D4 "빠른 작업" 줄·YubiKey 상단 버튼**: 상위 작업(받기·보내기·체인 바꾸기·연결·승인·토큰 추가·YubiKey 서명)이 이미 1–2 클릭이라 줄을 더하면 메인 첫 화면만 길어진다. 상단 막대 이름 변경(F1)과 설정 지도(F3)로 대신했다. YubiKey 관리는 가끔 하는 일이라 상단 버튼은 두지 않았다.
- **D5 Zcash `UTXO 원천`**: 기술 선택(노드 `getaddressutxos` / Blockbook)이 Zcash 탭 네트워크 카드에 있다(spec/12 §11). 다른 체인처럼 설정의 "고급"으로 옮기는 것을 제안한다 — 설정 구역을 새로 만드는 변경이라 남겼다.
- **D6 §7 문구의 다음 단계**: E-KEY-005 "설정 → 네트워크 URL에서…"의 위치 이름이 지금 탭 이름("네트워크(RPC)")과 다르다. §7 문구는 코드와 함께 고정이라(10-28·10-31과 같이) 별도 변경으로 남긴다.
- **D7 승인 무장 지연 자체**: 그대로 둔다. F4가 이유를 보여 준다.
- **D8 125–200% DPI 시각 확인, 버튼 hover 표시**: 이전 검토에서 남긴 그대로(수동 체크리스트 §10).
- **D9 설정·주소록 단축키**: Ctrl+,(설정) 같은 단축키는 쓰임이 적어 미뤘다. 단축키 줄(설정 → 정보)에 더하는 방식으로 언제든 넣을 수 있다.
