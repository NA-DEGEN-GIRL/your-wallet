# 처음 실제 사용 체크리스트 (짧은 버전)

서명 방식·주소 파생·승인 표시는 자동 테스트가 공식 벡터로 확인했다. 여기에는 실제 네트워크에서만 확인할 수 있는 것만 둔다.
처음에는 **소액**으로 한다.

## 1. 설치
- `install.cmd`를 실행한다. 저장소 폴더의 Low 레이블 때문에 묻는 창이 나오면 `계속`을 입력한다
  (레이블을 지우려면 `icacls "<저장소 폴더>" /setintegritylevel (OI)(CI)M`).
- Chrome `chrome://extensions`에서 Your Wallet 카드의 새로고침을 누른다.

## 2. RPC 연결
- 설정 → 네트워크(RPC)에서 **쓰는 체인만** `테스트`를 눌러 연결을 확인한다.

## 3. 쓰는 체인마다 한 번씩 (소액)
- **받기**: 거래소나 다른 지갑에서 소액을 보내 잔액이 보이는지 본다.
- **보내기**: 그 소액을 다시 내보내 도착하는지, 수수료가 상식적인지 본다.

## 4. 쓰는 기능만 한 번씩
- **dApp**(확장 또는 WalletConnect): 연결 → 소액 거래 1번.
- **YubiKey**: PIN 설정 → 소액 보내기 1번.
- **HyperCore 출금**: Arbitrum 도착 금액이 `입력 금액 − 1 USDC`인지 본다.

## 문제가 생기면
화면 캡처나 오류 코드(`E-…`)를 보낸다. 로그는 `%LOCALAPPDATA%\YourWallet\v3\logs\yw-app.log`
(설정 → 브라우저·정보 → `로그 폴더 열기`)에 있다. 복구 단어·비밀번호·키·RPC 주소는 들어 있지 않고, 내 주소와
거래 해시는 있을 수 있다.
